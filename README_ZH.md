# AI Communicate Skills

**让 AI 把工作讲清楚，方便你理解并做出判断。**

这个技能叫 **Communicate Clearly**。它帮助 AI 选择合适的讲解方式：几句简单的话、一张图、可以自己试着调整的小页面，或者在工具支持时做一段短视频。

**AI 声明：** 本仓库内容由 AI 根据人类提供的需求生成(含人量:0%)。

## 可以让它做什么？

- “讲清楚改了什么，以及为什么要改。”
- “画张图，说明这些部分怎样配合。”
- “让我试试不同选项，看看结果怎么变。”
- “一步步演示这个过程。”

目标是让你看得懂，有具体例子，也有可以核查的依据。

## 怎么开始？

把这句话发给你的 AI：

> 阅读 https://github.com/nehSgnaiL/ai-communicate-skills/blob/main/README_AI.md ，为当前项目安装 Communicate Clearly。

安装后，可以这样说：

> 用 Communicate Clearly 解释这项工作。先说结果，给我一个具体例子，再说明哪些地方还不确定。

以后想检查更新时，可以说：“看看 Communicate Clearly 有没有更新，并告诉我改了什么。”
